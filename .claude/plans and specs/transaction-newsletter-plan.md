# рассылка транзакций (счетов/актов)

Общие сведения:
- формирование документов сейчас идет по пайплайну: docx шаблон + данные -> docx документ -> pdf (через gotenberg)
- есть 2 ручных варианта запуска:
	- v1: ручная локальная через draft (пользователь потом отправляет вручную)
	- v2/var2: ручная локальная авто-отправка из контекстного меню (без draft, сразу отправляем по шаблону только итоговое сообщение)
- автоматический запуск (v2) выполняется при создании транзакций из шаблонов

3 стадии:

- [ ] v1: ручная локальная (как вложение) (в первую очередь)
- [ ] v2: автоматическая + ручная локальная (сразу письмом)
- [ ] v3: ручная массовая

**Лимит в 30 транзакций за пачку при ручных операциях**
## v1 - ручная локальная

Сценарий:

1. Пользователь выделяет 1..N транзакций в списке счетов/актов.
2. Нажимает в контекстном меню "Отправить как вложение". (2 варианта счёт/акт)
3. Система генерирует документы, создает draft, прикладывает файлы.
	 - тип документа для вложения выбирает пользователь
4. Открывается интерфейс почты на новом draft.
5. Пользователь дописывает письмо и отправляет вручную.

### второй вариант ручной локальной отправки (var2)

Сценарий var2:

1. Пользователь выделяет 1..N транзакций и запускает действие из контекстного меню.
2. Система формирует письмо в авто-режиме по той же схеме, что и в автоматической рассылке.
3. Получатели берутся из списка рассылки (`to`: staff транзакционного аккаунта с фильтрацией/дедупликацией).
4. Письмо отправляется сразу, без создания/открытия draft.
5. В интерфейсе показывается только итоговое сообщение об успешной отправке или агрегированная ошибка.

 **использовать шаблонизатор на фронте**
